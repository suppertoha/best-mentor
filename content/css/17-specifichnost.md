# Специфичность

Специфичность определяет, какое CSS-правило применится, если несколько селекторов нацелены на один элемент. Это основа каскада.

## Как считать вес

Грубо: id > class/атрибут/псевдокласс > тег/псевдоэлемент. Inline style перебивает id в файле (кроме !important).

- `p` — один тег
- `.btn` — один класс
- `#nav` — один id
- `button.primary[disabled]` — класс + тег + атрибут

## Порядок в файле

```css
.text {
  color: gray;
}

.text {
  color: navy; /* побеждает при равной специфичности */
}
```

## !important

Используй редко — ломает предсказуемость и усложняет override. Утилитарные классы и темы лучше проектировать без !important.

```css
.alert {
  color: #b91c1c !important; /* только если нет другого выхода */
}
```

## :where() для сброса веса

```css
:where(.prose h2) {
  margin-top: 2rem;
}

.prose h2 {
  margin-top: 3rem; /* перебьёт :where при равном контексте */
}
```

| Селектор | Пример веса |
| --- | --- |
| Элемент | `p` → 0,0,1 |
| Класс | `.card` → 0,1,0 |
| ID | `#main` → 1,0,0 |
| Inline | style= → 1,0,0,0 |

> Не поднимай специфичность ради победы — упрощай селекторы и структуру классов.

CSS-переменные помогают управлять значениями централизованно.
