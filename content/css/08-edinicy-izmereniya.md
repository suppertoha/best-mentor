# Единицы измерения

CSS предлагает абсолютные и относительные единицы. Выбор влияет на адаптивность, доступность и предсказуемость вёрстки.

## px, %, em, rem

px — фиксированные пиксели. % — от родителя. em — от font-size элемента (или родителя для font-size). rem — от корневого font-size (обычно html).

```css
html {
  font-size: 16px;
}

.title {
  font-size: 1.5rem; /* 24px */
  margin-bottom: 0.5em; /* от своего font-size */
}

.container {
  width: 90%;
  max-width: 1200px;
}
```

## vw, vh, vmin, vmax

Viewport units — процент от ширины/высоты окна. Удобны для hero-секций, но на мобильных vh может «скакать» при появлении адресной строки.

```css
.hero {
  min-height: 80vh;
  padding: 5vw;
}
```

## ch и fr

`ch` — ширина символа «0» в текущем шрифте (поля ввода). `fr` — доля свободного места в Grid/Flex.

```css
input[type="email"] {
  width: 24ch;
}

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
}
```

## Практические рекомендации

- font-size и отступы — rem для единообразия и zoom-доступности
- max-width контента — px или rem + % ширина
- Не злоупотребляй vw для основного текста — читаемость падает

| Единица | От чего считается |
| --- | --- |
| `rem` | font-size элемента html |
| `em` | font-size текущего элемента |
| `%` | Соответствующее свойство родителя |
| `fr` | Доступное место в grid/flex |

Цвета и градиенты задают визуальный стиль — следующий блок темы.
