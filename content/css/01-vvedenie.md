# Введение в CSS

**CSS** (Cascading Style Sheets) — язык стилей. Он описывает, **как выглядит** HTML: цвета, шрифты, отступы, расположение блоков.

HTML отвечает за структуру, CSS — за оформление.

## Как подключить CSS

**Внешний файл** (самый частый способ):

```html
<link rel="stylesheet" href="/styles/main.css" />
```

**Внутри HTML:**

```html
<style>
  h1 {
    color: #333;
  }
</style>
```

**Инлайн** (только для быстрых правок, в проектах лучше не злоупотреблять):

```html
<p style="color: red;">Красный текст</p>
```

## Базовый синтаксис

```css
селектор {
  свойство: значение;
}
```

Пример:

```css
h1 {
  color: #1a1a2e;
  font-size: 2rem;
  margin-bottom: 16px;
}
```

| Часть | Значение |
| ----- | -------- |
| `h1` | Селектор — к чему применяется правило |
| `color` | Свойство |
| `#1a1a2e` | Значение |

## Каскад и специфичность

Если несколько правил на один элемент, браузер выбирает «сильнейшее»:

1. Более **специфичный** селектор побеждает
2. При равной специфичности — правило **ниже** в файле
3. `!important` перебивает всё (используй редко)

```css
p {
  color: gray;
}

.intro {
  color: navy;
}
```

Для `<p class="intro">` текст будет **navy**.

## Единицы измерения

```css
.box {
  width: 100%;      /* от родителя */
  max-width: 720px; /* пиксели */
  padding: 1rem;    /* относительно корневого шрифта */
  font-size: 16px;
}
```
