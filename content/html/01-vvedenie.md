# Введение в HTML

**HTML** (HyperText Markup Language) — язык разметки веб-страниц. Браузер читает HTML и строит из него страницу: заголовки, текст, ссылки, картинки, формы.

HTML **не** программирование в привычном смысле: ты описываешь **структуру** документа, а не алгоритмы.

## Зачем учить HTML

- Понимать, из чего состоит любая веб-страница
- Уверенно читать вёрстку в DevTools
- Готовиться к CSS и JavaScript

## Базовый каркас страницы

Любой HTML-документ начинается с объявления типа и корневого тега:

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <title>Моя первая страница</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый абзац.</p>
  </body>
</html>
```

| Часть | Назначение |
| ----- | ---------- |
| `<!DOCTYPE html>` | Сообщает браузеру, что это HTML5 |
| `<head>` | Служебная информация (кодировка, заголовок вкладки) |
| `<body>` | Всё, что видит пользователь на странице |

## Теги и атрибуты

- **Тег** — элемент разметки: `<p>`, `<a>`, `<img>`
- **Атрибут** — дополнительное свойство тега: `href`, `src`, `alt`

```html
<a href="https://developer.mozilla.org/ru/docs/Web/HTML">Документация MDN</a>
```

## Парные и одиночные теги

**Парные** — есть открывающий и закрывающий тег:

```html
<p>Текст внутри абзаца</p>
```

**Одиночные** — без закрывающего тега (в HTML5):

```html
<img src="cat.jpg" alt="Кот" />
<br />
```

> Семантика важна: используй теги по смыслу (`h1` для главного заголовка, `p` для абзаца), а не «чтобы было жирным».
