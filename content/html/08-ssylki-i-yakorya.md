# Ссылки и якоря

Ссылки соединяют страницы и разделы внутри документа. Якоря позволяют прыгать к нужному заголовку без перезагрузки всей страницы.

## Внешние и внутренние ссылки

Атрибут `href` задаёт адрес. Для перехода на другой сайт указывай полный URL; для страниц своего проекта — относительный путь.

```html
<a href="https://developer.mozilla.org/">MDN</a>
<a href="/about.html">О проекте</a>
<a href="../index.html">На главную</a>
```

## Якорные ссылки

Ссылка с `#id` ведёт к элементу с таким же `id` на странице. Идентификатор должен быть уникальным.

```html
<nav>
  <a href="#intro">Введение</a>
  <a href="#practice">Практика</a>
</nav>

<h2 id="intro">Введение</h2>
<p>Текст раздела...</p>

<h2 id="practice">Практика</h2>
<p>Задания для закрепления...</p>
```

## target и rel

Открытие в новой вкладке: `target="_blank"`. Всегда добавляй `rel="noopener noreferrer"` из соображений безопасности.

```html
<a
  href="https://example.com/docs"
  target="_blank"
  rel="noopener noreferrer"
>
  Документация (откроется в новой вкладке)
</a>
```

## Ссылки на email и телефон

Схемы `mailto:` и `tel:` запускают почтовый клиент или набор номера на мобильных устройствах.

```html
<a href="mailto:hello@example.com">Написать нам</a>
<a href="tel:+74951234567">+7 (495) 123-45-67</a>
```

## Доступные ссылки

Текст ссылки должен быть понятен вне контекста. Избегай «нажми здесь» без пояснения, куда ведёт переход.

- Описывай назначение: «Скачать программу курса (PDF)»
- Для иконок без текста используй aria-label
- Не делай несколько ссылок на один и тот же URL с разным текстом без причины

Проверяй все href вручную и в DevTools: битые ссылки портят опыт пользователя и доверие к сайту.
