# Кодировка

Кодировка определяет, как байты файла превращаются в символы. Неверная кодировка — причина «кракозябр» вместо русского текста.

## UTF-8 как стандарт

UTF-8 поддерживает кириллицу, эмодзи и символы большинства языков. Для веба это де-факто единственный разумный выбор.

```html
<meta charset="UTF-8" />
```

## Порядок объявления charset

Тег charset должен быть в первых 1024 байтах документа — лучше поставить его сразу после `<head>`, до `<title>`.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <title>Кодировка UTF-8</title>
  </head>
  <body>
    <p>Привет, мир! 🌍</p>
  </body>
</html>
```

## Кодировка файла в редакторе

HTML объявляет кодировку, но сам файл тоже должен быть сохранён в UTF-8. Проверь настройки редактора: «Save with UTF-8» или «UTF-8 without BOM».

- VS Code: в статус-баре отображается UTF-8
- BOM для HTML обычно не нужен
- При копировании из Word проверяй спецсимволы

## HTML-сущности

Некоторые символы в разметке пишут через именованные сущности или числовые коды.

```html
<p>Знак &lt; меньше, &amp; амперсанд, &copy; копирайт.</p>
<p>Числовой код: &#8381; — символ рубля.</p>
```

## HTTP-заголовок Content-Type

Сервер может дополнительно сообщать кодировку в заголовке ответа. Важно, чтобы он совпадал с meta charset.

```html
Content-Type: text/html; charset=UTF-8
```

Если видишь нечитаемый текст — сначала проверь charset в HTML и кодировку сохранения файла.
