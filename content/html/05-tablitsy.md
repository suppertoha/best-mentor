# Таблицы

Таблицы в HTML предназначены для табличных данных: расписания, прайс-листы, сравнения характеристик. Для вёрстки страниц таблицы не используют — для этого есть CSS Grid и Flexbox.

## Базовая структура таблицы

Минимальный набор: `<table>`, строки `<tr>`, ячейки `<td>`. Заголовки столбцов оформляют через `<th>`.

```html
<table>
  <tr>
    <th>Язык</th>
    <th>Год появления</th>
    <th>Область</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>1991</td>
    <td>Разметка</td>
  </tr>
  <tr>
    <td>CSS</td>
    <td>1996</td>
    <td>Стили</td>
  </tr>
</table>
```

## thead, tbody и tfoot

Группировка частей таблицы упрощает стилизацию и делает разметку понятнее для скринридеров.

```html
<table>
  <thead>
    <tr>
      <th>Товар</th>
      <th>Цена</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Клавиатура</td>
      <td>4 990 ₽</td>
    </tr>
    <tr>
      <td>Мышь</td>
      <td>1 290 ₽</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th>Итого</th>
      <td>6 280 ₽</td>
    </tr>
  </tfoot>
</table>
```

## Объединение ячеек

Атрибуты `colspan` и `rowspan` растягивают ячейку на несколько столбцов или строк.

```html
<table>
  <tr>
    <th rowspan="2">Курс</th>
    <th colspan="2">Оценка</th>
  </tr>
  <tr>
    <th>Теория</th>
    <th>Практика</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>5</td>
    <td>5</td>
  </tr>
</table>
```

## Подпись и доступность

Элемент `<caption>` задаёт заголовок таблицы. Атрибут `scope` у `<th>` указывает, к чему относится заголовок — к столбцу или строке.

```html
<table>
  <caption>Расписание занятий на неделю</caption>
  <thead>
    <tr>
      <th scope="col">День</th>
      <th scope="col">Время</th>
      <th scope="col">Тема</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Понедельник</th>
      <td>18:00</td>
      <td>Семантика HTML</td>
    </tr>
  </tbody>
</table>
```

## Стилизация таблиц

Базовое оформление задаётся через CSS: границы, отступы, чередование строк.

```css
table {
  width: 100%;
  border-collapse: collapse;
}

th,
td {
  border: 1px solid #ccc;
  padding: 8px 12px;
  text-align: left;
}

tbody tr:nth-child(even) {
  background-color: #f7f7f7;
}
```

> Таблица — для данных, а не для сетки страницы. Если нужны колонки без табличных данных, используй CSS.

Перед публикацией проверь, что у каждой ячейки есть смысл, а заголовки связаны с данными через `scope` или явную структуру.
