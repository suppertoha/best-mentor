# Теги и структура HTML

В этой главе — основные теги для текста, списков, ссылок и скелет страницы.

## Заголовки

От `h1` (главный) до `h6` (самый мелкий). На странице обычно **один** `h1`.

```html
<h1>Главный заголовок</h1>
<h2>Подзаголовок раздела</h2>
<h3>Подпункт</h3>
```

## Текст и выделение

```html
<p>Обычный абзац с <strong>важным</strong> и <em>акцентным</em> текстом.</p>
<p>Строка кода в тексте: используй тег <code>code</code>.</p>
```

## Списки

**Маркированный:**

```html
<ul>
  <li>Пункт один</li>
  <li>Пункт два</li>
</ul>
```

**Нумерованный:**

```html
<ol>
  <li>Шаг 1</li>
  <li>Шаг 2</li>
</ol>
```

## Ссылки и изображения

```html
<a href="/sections">К разделам курса</a>

<img src="/images/schema.png" alt="Схема HTML-документа" width="400" />
```

`alt` обязателен для доступности: если картинка не загрузилась, пользователь увидит описание.

## Семантические блоки

```html
<header>
  <nav>
    <a href="/">Главная</a>
    <a href="/profile">Профиль</a>
  </nav>
</header>

<main>
  <article>
    <h1>Статья</h1>
    <p>Содержание статьи.</p>
  </article>
</main>

<footer>
  <p>© 2026 Best Mentor</p>
</footer>
```

| Тег | Смысл |
| --- | ----- |
| `header` | Шапка страницы или раздела |
| `nav` | Навигация |
| `main` | Основной уникальный контент |
| `article` | Самостоятельный материал (статья, глава) |
| `footer` | Подвал |

## Цитата

```html
<blockquote>
  <p>HTML описывает структуру. CSS — внешний вид. JavaScript — поведение.</p>
</blockquote>
```

## Мини-шпаргалка

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <title>Теги и структура</title>
  </head>
  <body>
    <h1>Заголовок</h1>
    <p>Абзац со <a href="#">ссылкой</a>.</p>
    <ul>
      <li>элемент списка</li>
    </ul>
  </body>
</html>
```

Попробуй открыть эту разметку в браузере и поэкспериментировать в DevTools.
