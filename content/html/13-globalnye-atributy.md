# Глобальные атрибуты

Глобальные атрибуты можно ставить почти на любой HTML-элемент. Они управляют идентификаторами, классами, доступностью, перетаскиванием и скрытием контента.

## id и class

`id` уникален на странице и нужен для якорей и связи с label. `class` — для CSS и выборки в JS, значений может быть несколько.

```html
<p id="lead" class="text text--large highlight">
  Вводный абзац статьи.
</p>
```

## hidden и contenteditable

`hidden` полностью скрывает элемент от отображения и доступности (если не переопределено CSS). `contenteditable` разрешает редактирование прямо в браузере.

```html
<p hidden>Черновик, не показывать пользователю.</p>

<div contenteditable="true">
  Кликни и отредактируй этот текст.
</div>
```

## title и lang

Атрибут `title` показывает всплывающую подсказку при наведении. `lang` на элементе переопределяет язык фрагмента.

```html
<abbr title="HyperText Markup Language">HTML</abbr>

<p>
  Цитата на английском:
  <q lang="en">Practice makes perfect.</q>
</p>
```

## draggable и tabindex

`draggable="true"` включает drag-and-drop. `tabindex` управляет порядком фокуса с клавиатуры: 0 — в общем порядке, -1 — программный фокус.

```html
<div draggable="true" class="card">Перетащи меня</div>

<button type="button" tabindex="0">В фокусе по Tab</button>
<button type="button" tabindex="-1">Только программный фокус</button>
```

## style и data-*

Инлайн-стили через `style` лучше избегать в пользу классов. Префикс `data-` хранит произвольные данные для скриптов — подробнее в отдельной главе.

```html
<span class="badge badge--new">Новинка</span>

<!-- Плохо для поддержки: -->
<p style="color: red; font-size: 20px;">Избегай инлайн-стилей</p>
```

Не злоупотребляй глобальными атрибутами: id должен быть уникальным, а tabindex — осмысленным для клавиатурной навигации.
