# Списки

Списки структурируют перечисления: пункты меню, шаги инструкции, термины со значениями. HTML предлагает три основных типа списков.

## Маркированный список ul

Элемент `<ul>` содержит пункты `<li>`. Порядок не важен — подходит для меню и наборов свойств.

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

## Нумерованный список ol

`<ol>` нумерует пункты автоматически. Атрибут `start` задаёт начальное число, `reversed` — обратный порядок.

```html
<ol>
  <li>Установить редактор кода</li>
  <li>Создать файл index.html</li>
  <li>Открыть страницу в браузере</li>
</ol>

<ol start="5" reversed>
  <li>Пятый шаг</li>
  <li>Четвёртый шаг</li>
</ol>
```

## Список определений dl

`<dl>` связывает термин `<dt>` с описанием `<dd>`. Удобно для глоссариев и FAQ.

```html
<dl>
  <dt>API</dt>
  <dd>Интерфейс для обмена данными между программами.</dd>

  <dt>DOM</dt>
  <dd>Объектная модель документа в браузере.</dd>
</dl>
```

## Вложенные списки

Внутри `<li>` можно размещать другой список — так строят многоуровневые меню и планы.

```html
<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend
    <ul>
      <li>Node.js</li>
      <li>Базы данных</li>
    </ul>
  </li>
</ul>
```

## Списки и навигация

Меню сайта часто размечают как список ссылок внутри `<nav>`.

```html
<nav aria-label="Основное меню">
  <ul>
    <li><a href="/">Главная</a></li>
    <li><a href="/courses">Курсы</a></li>
    <li><a href="/contacts">Контакты</a></li>
  </ul>
</nav>
```

Выбирай тип списка по смыслу: ul — без порядка, ol — с порядком, dl — термин и определение.
