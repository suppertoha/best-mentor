# Изображения

Изображения делают страницу наглядной, но увеличивают вес документа. Правильные форматы, размеры и альтернативный текст — обязательная часть грамотной вёрстки.

## Тег img

`<img>` — одиночный тег. Обязательные атрибуты: `src` (путь к файлу) и `alt` (текстовое описание для доступности и при ошибке загрузки).

```html
<img
  src="/images/team-photo.jpg"
  alt="Команда разработчиков на конференции"
  width="800"
  height="450"
/>
```

## Атрибуты width и height

Явные размеры резервируют место под картинку до загрузки и уменьшают сдвиг макета (CLS). Значения можно задавать в HTML, а масштаб — в CSS.

```html
<img
  src="avatar.png"
  alt="Аватар пользователя"
  width="96"
  height="96"
  class="avatar"
/>

<style>
  .avatar {
    width: 48px;
    height: 48px;
    border-radius: 50%;
    object-fit: cover;
  }
</style>
```

## Адаптивные изображения с srcset

Атрибут `srcset` позволяет браузеру выбрать файл под плотность экрана или ширину viewport.

```html
<img
  src="hero-800.jpg"
  srcset="
    hero-400.jpg 400w,
    hero-800.jpg 800w,
    hero-1200.jpg 1200w
  "
  sizes="(max-width: 600px) 100vw, 800px"
  alt="Горный пейзаж на рассвете"
/>
```

## picture для разных форматов

Элемент `<picture>` подключает WebP или AVIF с запасным вариантом для старых браузеров.

```html
<picture>
  <source srcset="banner.avif" type="image/avif" />
  <source srcset="banner.webp" type="image/webp" />
  <img src="banner.jpg" alt="Баннер курса по вёрстке" />
</picture>
```

## Декоративные изображения

Если картинка не несёт информации, оставь пустой `alt`. Для иконок рядом с текстом это нормальная практика.

- Информативное изображение — осмысленный alt
- Декоративное — alt=""
- Изображение-ссылка — alt описывает цель перехода

Сжимай файлы, указывай размеры и не забывай про alt: это влияет и на доступность, и на SEO.
