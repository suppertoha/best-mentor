# SEO

SEO (Search Engine Optimization) — набор практик, помогающих поисковикам понять и показать твою страницу. HTML задаёт фундамент: заголовки, метаданные, структура ссылок.

## Один h1 и иерархия заголовков

Заголовок `<h1>` отражает главную тему. Подзаголовки `<h2>`–`<h6>` раскрывают структуру статьи.

```html
<main>
  <h1>Гайд по семантической вёрстке</h1>
  <h2>Зачем нужны семантические теги</h2>
  <h2>Примеры разметки</h2>
  <h3>Шапка и подвал</h3>
</main>
```

## title и meta description

Уникальные title и description на каждой странице улучшают кликабельность в выдаче.

```html
<title>Семантическая разметка HTML — курс для начинающих</title>
<meta
  name="description"
  content="Учим header, main, article и другие теги HTML5 на практических примерах."
/>
```

## ЧПУ и канонический URL

Человекопонятные URL и тег `link rel="canonical"` снижают дублирование контента.

```html
<link rel="canonical" href="https://example.com/courses/html/semantic" />
```

## Ссылки и alt у изображений

Внутренняя перелинковка помогает обходу сайта. Текст alt описывает изображение для поиска по картинкам.

```html
<a href="/courses/html/tables">Следующая глава: таблицы</a>

<img src="semantic-structure.png" alt="Схема семантической структуры страницы" />
```

## robots и sitemap

Файл `robots.txt` и карта сайта `sitemap.xml` подсказывают роботам, что индексировать. Это не HTML-файлы страницы, но тесно связаны с SEO.

- Не блокируй важные страницы в robots без причины
- Добавляй в sitemap только канонические URL
- Проверяй мобильную версию и скорость загрузки

SEO начинается с чистой семантической разметки и уникальных метаданных — без этого сложные стратегии малоэффективны.
