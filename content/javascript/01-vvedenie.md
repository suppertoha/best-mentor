# Введение в JavaScript

**JavaScript** — язык программирования в браузере. Он добавляет **поведение** странице: клики, формы, запросы к API, анимации.

| Технология | Роль |
| ---------- | ---- |
| HTML | Структура |
| CSS | Внешний вид |
| JavaScript | Логика и интерактивность |

## Где выполняется JS

1. **В браузере** — фронтенд (наш проект Best Mentor)
2. **На сервере** — Node.js (бэкенд)

В этой главе — основы синтаксиса, общие для обоих миров.

## Подключение в HTML

```html
<script src="/app.js"></script>
```

Или внутри страницы:

```html
<script>
  console.log("Привет, JavaScript!");
</script>
```

## Первая программа

```js
console.log("Hello, world!");

const courseName = "Best Mentor";
console.log(courseName);
```

`console.log` — вывод в DevTools → вкладка **Console**.

## Комментарии

```js
// однострочный комментарий

/*
  многострочный
  комментарий
*/
```

## Простые операции

```js
const a = 10;
const b = 3;

console.log(a + b);  // 13
console.log(a > b);  // true
console.log(a === 10); // true (строгое сравнение)
```

## alert и prompt (для экспериментов)

```js
alert("Сообщение пользователю");

const name = prompt("Как тебя зовут?");
console.log(name);
```

В реальных приложениях вместо `alert` используют UI-компоненты (как наши тосты в React).
